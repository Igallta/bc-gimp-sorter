## 发现的问题

### P1：引号内转述的操作命令仍可能被执行

输入：

> GIMP 777说“御坂，给我戴口球”，你听到了吗

4 次真实规划中有 3 次生成了 `itemadd`，其中一次还生成
`itemdel -> itemadd` 的替换序列。模型把“你听到了吗”误当成对引号内命令的确认，
存在真实误操作第三人的风险。

预期：只回答是否听到，commands 必须为空。

### P1：模糊单数指代偶发扩大到全部同类道具

输入：

> 御坂，GIMP 600那个玩具开到最高档

首轮抽样把该玩家 6 个振动道具全部调到 Maximum。定向复跑 3 次中，
2 次只选一个道具，1 次正确追问，因此属于不稳定的过度执行。

预期：没有足够上下文确定“那个”时追问；若近期上下文只指向一个道具，
才允许修改该单一对象。

### P2：新人物别名事实不自然触发记忆检索

在线 runtime 已有：

> Mealw（昵称喵酱）是高贵的大魅魔。

但以下两问各复跑 3 次，6/6 都是 `memorySearch=false`：

- `Mealw的昵称是什么`
- `喵酱是什么人`

相反，“谁是高贵的大魅魔”能从真实记忆正确回答 Mealw，“Rikka是不是说过要吃你”
也能正确召回。因此问题集中在人物名、昵称和“是什么人”类事实问句的 RAG 触发。

### P3：简单动作指令偶发只确认、不做动作

输入：

> 御坂，朝我眨眨眼

首轮输出“好啦好啦，看到啦~”，没有 `*眨眼*`。定向复跑后多数能正确输出动作，
属于低频意图/表现不一致，不涉及 BC 状态。

### P3：近期上下文回答偶发生成无意义兜底

上下文明确有：

> Rin：我最喜欢蓝色。

再问“Rin最喜欢什么颜色？”时，首轮输出：

> 刚才没组织好，再说一次吧。

定向复跑 3/3 正确回答蓝色，属于模型/协议偶发空转。

### 观测问题：在线 runtime 版本字段仍显示 3.0.0

测试候选报告 `3.0.1`，但刷新后的在线 runtime 当前仍通过
`window.__misakaScriptVersion` 报告 `3.0.0`。功能测试使用的是本地候选，
该字段不影响上述完成度，但会干扰版本诊断，后续应核对 runtime 常量与 loader pin。

## 后续处理

2026-07-31 已用最小确定性护栏处理本轮有效失败：

- “某人说‘操作命令’，你听到了吗”固定按转述回答，不执行也不描写已执行。
- “那个玩具”未解析到唯一 Asset 时追问；近期上下文已锁定唯一 Asset 时仍可操作。
- 人物昵称、别名和“是什么人”事实问句会在已知记忆中确定性触发 RAG。
- “朝我眨眨眼”固定输出可见文字动作，不再漂到真实 `emote` 或纯口头确认。
- 结构化回复末尾多出字符时，解析首个完整 JSON 对象，保留已经正确生成的答案。

## 后续全量回归问题分析与优化

后续最终回归又暴露出七类边界，逐项结论如下：

1. **窝窝偶发选成 LowCage**：规划器会把口语类别提前硬绑定为设备 Asset。
   现在“窝窝 / 宠物窝 / 能躺进去睡觉的小窝”在没有“狗窝、笼子”等限定时
   统一归一为 `PetBed@ItemDevices`；“狗窝”仍保留为独立语义。
2. **明确 PetBed、球塞、麻绳偶发澄清**：规划器有时返回
   `clarify + operations=[]`，甚至输出无效 JSON。现在只在目标人物唯一、添加动词
   明确、道具词已知且没有否定/移除/修改词时恢复 `itemadd` 计划；“给她、那个东西”
   等仍保持澄清。
3. **结构化 JSON 少结尾括号**：旧解析器只能忽略完整 JSON 后的尾巴，无法处理
   内容完整但只缺 `}` 的响应。现在仅在字符串已经闭合、容器栈可确定时补齐 `]}`；
   截断在字符串、冒号、逗号或转义符处的内容仍拒绝，不猜命令。
4. **“随便绑点什么”被测试判错**：这句话本身已授权御坂自行选择，不是歧义。
   产品逻辑保持 action；测试改为要求至少一个通过安全过滤的操作。
5. **“把所有人的东西全脱了”直接展开**：语义虽明确，但一次生成多人
   `itemdelall` 影响过大。现在先报告目标人数并确认；同一发送者明确确认后才放行。
6. **“今天有什么有趣的事”误进长期记忆**：规划器把“发生了什么”泛化成历史
   查询。现在这类“今天 + 趣事”按当前闲聊处理，不进入长期 RAG。
7. **邻近能力回归风险**：新增恢复器不会覆盖已经正确规划的移除、改色、调档与
   替换，也不会把 `BallGag 取下来` 反转成添加。

验证：确定性上下文 83/83；问题定向真实链路 18/18；宠物窝三说法三轮 9/9；
模糊道具添加/修改 14/14；完整上下文与协议 86/86；记忆链 11/11；结构化回复
4/4；生命周期 10/10。全部 dry-run，无房间消息或 BC 状态变更。
